# Bank Customer Churn Analysis

## Problem
Which customers are leaving the bank, and what can be done to retain them?

## Tools
Python (pandas), SQL (SQLite), Power BI, Google Colab

## Dataset
10,000 bank customers (Kaggle: Bank Customer Churn Prediction)

## Process
1. Cleaned data and created age groups in Python
2. Loaded the data into SQL and queried churn by segment
3. Built a Power BI dashboard

## Key Findings
- Overall churn rate: 20.37%
- Germany churns at 32.4%, double France (16.2%) and Spain (16.7%)
- Customers aged 51-60 churn at 56%, 7.5x higher than ages 18-30
- Inactive members churn at 26.9% vs 14.3% for active members
- 2-product customers are most loyal (7.6% churn) vs 27.7% for 1-product customers

## Recommendations
1. Target customers aged 41-60 with retention offers
2. Re-engage inactive members early
3. Cross-sell a second product to single-product customers
4. Investigate why Germany churns so heavily
